## Global packaging

The offline builder reconstructs baseline sources from verified manifested
files, then uses the existing global release renderer. It does not edit live
sources, settings, hooks, indexes or projections:

```bash
python3 scripts/prepare_global_candidate.py \
  --config "$HOME/.config/ai-agents" --output evals/local/global-v3.1-NEW
```

This helper requires the maintainer's external `ai-agents` renderer and release
manifest format; those tools are not bundled with this repository. It is a
one-time migration from the pre-v3.1 guardrail text, not an installer or an
idempotent updater for an already migrated release. Use a fresh output directory.

receive the corrected guardrail blocks; existing mode, diagram, recap, footer

from the minimal experimental prompt and cannot inherit its measurements.
