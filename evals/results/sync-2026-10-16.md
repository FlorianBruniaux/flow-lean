Historical report: the original grades below are retained for provenance.

suite, which includes five new cases for the synced rules. It is a regression
check, not a benchmark: one trial per case, and the same model family both
generates and grades.

## Runner

The runner is [`sync-2026-10-16-runner.json`](sync-2026-10-16-runner.json),
using `claude-sonnet-5` through Claude Code with these settings:

- `--tools ""` and `--strict-mcp-config`: no built-in tools and no MCP
  servers. The `init` event lists zero tools.
- `--system-prompt "You are a helpful assistant."`: replaces the coding-agent
  prompt.
- The working directory is an empty temporary directory. This is a local
  harness change, not committed; the committed harness uses the repository
  root.
- Runner output is decoded as UTF-8 (#5).

Earlier runs that had only `--tools ""` (or the default runner) produced
written-out tool calls with no answer, plus references to the local
repository path and branch. That run was discarded and is not reported here.

**Remaining leak:** Claude Code still injects the working directory, the git
flag, the OS and the date, even with `--exclude-dynamic-system-prompt-sections`.
Full text isolation needs a direct API runner.

## Reading

- The weighted scores show no difference between `main` and the candidate.
  This is not evidence of improvement.
- `rollback-concurrent-edits` passes on both versions in this run: 4.25 for
  `main`, 4.85 for the candidate. Earlier runs failed on both, so this case
  stays noisy and is reported apart from any average.
- The debug-spiral cases still fall short of the "one focused question"
  criterion on both versions. The rule improves the score, but its effect is
  not reliable.
- The em dash rule: responses containing U+2014 were 1/30 for `main` and 2/30
  for the candidate.
